# Principles

Status: Approved Version: 1.0.0

1.  Skills are Dispatchers.
2.  Knowledge is written as enforceable contracts, not human
    documentation.
3.  Knowledge is Atomic.
4.  Route over Search.
5.  Minimize Context.
6.  Compose, Don't Duplicate.
7.  Official Guidance First.
8.  Explicit Dependencies.
9.  Validation Before Formalization.
10. Stable Architecture, Evolving Knowledge.
11. Agent-Agnostic.

Editor's Note: Framework-agnostic unless necessary and optimize for
coding agents are treated as implementation rules under Principles 2 and
5.
